# OSN C-Shell

A custom Unix-like shell implemented in C as part of the Operating Systems and Networks (OSN) course mini-project.

## Overview

This project implements a command-line shell with support for built-in commands, external command execution, input/output redirection, pipes, background processes, and job control.

## Project Structure

- `src/` – C source files
- `include/` – Header files
- `Makefile` – Build configuration
- `shell.tcl` – Automated testing script

## Language

- C
- Unix system calls

More details about implementation and usage will be added as the project documentation progresses.
